# TaskbarCat

タスクバーの上で暮らす灰色の猫。歩く・立ち止まる・座る・寝る・伸びをする、をくり返し、ときどき吹き出しでしゃべる。
決まった時刻（または猫のきまぐれ）にスクリプトを実行して、結果を吹き出しで教えてくれる機能もある。

- Windows 10 / 11 用。exe 1つで動き、インストール不要（.NET Framework 4.x は Windows に標準で入っている）
- メモリ 10MB 前後、CPU はほぼ使わない

## はじめかた（受け取った人向け）

1. zip を展開する
   - ダウンロードした zip は、展開する前に **右クリック →「プロパティ」→ 下の「許可する」にチェック → OK** をしておくと、警告が出にくくなる
   - 展開先は `C:\Tools\taskbar-cat` やドキュメント配下など、自分が書き込める場所にする（`Program Files` は不可。設定やログを exe の隣に書くため）
2. `taskbar-cat\TaskbarCat.exe` をダブルクリック
   - 「Windows によって PC が保護されました」と出たら **「詳細情報」→「実行」**（公的な署名のない自作 exe のため）
3. タスクバーの上に猫が出てくれば OK
4. PC 起動時に自動で出したい場合: `Win+R` → `shell:startup` を開き、`TaskbarCat.exe` のショートカットを置く

## 使い方

- 左クリック: 歩いている時はびっくりジャンプ、座っている時はハート、寝ている時は起きる
- 右クリック:
  - 「隠れる」… 右下の隅に移動し、しっぽだけ出して待機。もう一度押すと出てくる
  - 「タスク」… 登録した単発バッチの一覧・単発バッチの設定・スケジュール設定・ログを開く
  - 「外見」… しゃべる ON/OFF・エフェクト ON/OFF・大きさ（小/中/大）
  - 「設定」… 保存先（下記）
  - 「ポートを調べる」… ポート番号から使っているプロセス（PID）を探し、右クリックで終了できる（下記）
  - 「タスクマネージャー」「コントロールパネル」… Windows の標準ツールを開くショートカット
  - 「再起動」「終了」
- 隠れている時は、しっぽの周りを右クリックすればメニューが開く。見失った時は `TaskbarCat.exe` をもう一度起動すると出てくる
- 全画面アプリ（動画・ゲーム等）表示中は自動で隠れる
- exe のあるフォルダには何も書き込まない（スタートアップに exe を置いても散らからない）。設定やログは次の2か所に置く
- ホームフォルダ `%USERPROFILE%\.taskbar-cat`（初回起動時に自動作成）
  - 設定 `TaskbarCat.ini` は常にここ（保存先の設定もここに持つので動かせない）
  - `schedule.txt`・`oneshot.txt` に書いた相対パスと、`data=` の相対パスは、どれもここが基準
- 保存先: `logs\`・`schedule.txt`・`oneshot.txt`・`messages.txt` を置くフォルダ。既定はホームフォルダ
  - 「設定」→「保存先」→「フォルダを選ぶ…」で変更する。今のファイルをコピーするか聞かれ、猫が再起動する（ログは移さない）
  - 「既定（…\.taskbar-cat）」でホームフォルダに戻す。「保存先を開く」でエクスプローラーが開く
  - `TaskbarCat.ini` の `data=` に直接書いてもよい（`%USERPROFILE%` などの環境変数も使える）。使えないフォルダの時はホームフォルダになる
- 猫のひとり言を変えたい時: 保存先に `messages.txt`（UTF-8、1行1セリフ）を置く

## 単発バッチ

よく使うバッチやスクリプトを登録しておき、右クリック →「タスク」を開くと上に一覧が並ぶので、選んで1回実行する。

- 登録は「タスク」→「単発バッチの設定…」の画面で行う（追加 / 編集 / 削除 / 並べ替え / 今すぐ実行）
- 名前は省略可（空ならファイル名がメニューに出る）
- **ショートカットキー**: 登録画面の「ショートカット」欄を選んでキーを押すと割り当てられる（例: `Ctrl+Alt+B`）。どのアプリを使っていても、押すと確認なしで即実行する
  - Ctrl / Alt / Win のどれかとの組み合わせが必要（Shift は追加で使える）。Backspace か「解除」で外す
  - ほかの単発バッチと同じキーは使えない。ほかのアプリや Windows が使っているキーは保存時に警告が出て、そのままでは効かない（ログに `[ショートカット]` で残る）
  - 割り当てたキーはメニューの名前の右側に表示される
- .bat / .cmd / .ps1 / .py は常にバックグラウンドで実行し、コンソールのウィンドウは出さない（その他のファイルはダブルクリックと同じ）
  - 標準入力はすぐ閉じるので、`pause` や `set /p` は入力を待たずに先へ進む（見えないまま止まり続けることはない）
- 実行方法・吹き出し・ログはスケジュール実行と同じ（下記）
- 中身は保存先の `oneshot.txt`（`メニューに出す名前 | 実行するファイル | ショートカットキー` を1行ずつ。キーは省略可）。メモ帳で直接編集してもよく、メニューは次に開いた時、ショートカットキーは1分以内に反映される（以前の `| ウィンドウ表示` は無視される）

## ポートを調べる

右クリック →「ポートを調べる」で開く。`netstat -ano | findstr :3000` → `taskkill /PID 1234 /F` を画面でやるもの。

- ポート番号を入れて Enter（または「検索」）。ローカル・リモートどちらかのポートが一致する行が出る（ローカルが一致する行が先）
- ポート欄を空のまま検索すると、待ち受け中（LISTEN）の一覧。「UDP も含める」で UDP も出す
- 一覧は検索した時だけ取る（自動更新はしない）。取り直すのは「再読み込み」か F5
- 行を右クリック →「プロセスを終了…」で、確認のあと終了する。ほかに PID / 行のコピー、ファイルの場所を開く
- 次のプロセスは終了できない（行がグレーになり、選ぶと理由が出る）: System、猫自身、サービスやほかのユーザーのプロセス、`C:\Windows` 配下のもの、Windows・セキュリティ製品の部品（`Ports.cs` の `Protected`）
- 管理者権限には昇格しない。管理者権限で動いているプロセスは止められない
- 終了した結果は `logs\日付.log` に `[ポート]` で残る

## スケジュール実行

右クリック →「タスク」→「スケジュール設定…」で設定画面が開く。

- 追加 / 編集 / 削除 / 今すぐ実行。チェックを外すと一時停止（変更はすぐ保存）
- タイミングは次から選ぶ。曜日はチェックで選ぶ
  - 時刻を指定（例: 平日 09:00）
  - 一定間隔（5分ごと、9〜18時台のみ 等）
  - きまぐれ（既定。30〜120分おきにランダム。範囲は変更可）
  - cron で指定
- 実行方法: `.ps1` → PowerShell、`.bat`/`.cmd` → cmd、`.py` → python（いずれもウィンドウなし）、その他 → ダブルクリックと同じ
- スクリプトが標準出力に何か書いたら、その内容を吹き出しで表示する（「しゃべる」OFF でも表示）。出力がなければ猫語で成功/失敗だけ
- 出力・終了コードは `logs\日付.log` に残る（「タスク」→「ログを開く」）
- 猫が起動している間だけ動く。スリープ等で過ぎた時刻は実行しない（cron と同じ。きまぐれは復帰後すぐ実行）

中身は保存先の `schedule.txt`（初回に自動作成）。メモ帳で直接編集してもよく、保存すると1分以内に反映される:

```
# 分 時 日 月 曜日   | 実行するファイル        | 猫のセリフ(省略可)
0 9 * * 1-5          | C:\scripts\morning.ps1 | 朝のやつ動かすにゃ
*/15 9-18 * * 1-5    | C:\scripts\check.py
@random 30-120       | C:\scripts\kimagure.ps1
#off 30 12 * * *     | C:\scripts\lunch.bat          ← #off で始まる行は一時停止中
```

- 曜日は 0=日〜6=土（7 も日）。`*` `1-5` `1,3,5` `*/15` `9-18/2` が使える
- ファイルはフルパス、または exe からの相対パス。`%USERPROFILE%` などの環境変数も使える

## ソースからビルドする（開発者向け）

必要なもの: Windows 10/11 のみ（`build.bat` は Windows 標準の `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe` を使う。Visual Studio 不要）

```
build.bat        # *.cs と assets\sprites\*.png（exe に埋め込み）から TaskbarCat.exe を作る
```

- 猫が起動中だと exe を上書きできないので、先に右クリック →「終了」しておく
- ビルド後に `tools\sign.ps1` で exe に自己署名する（証明書 `CN=TaskbarCat Dev` は初回に現在のユーザーの証明書ストアへ自動作成、以後使い回し）
  - 自己署名なので SmartScreen の警告は消えない（改ざん検知と「誰がビルドしたか」の目印）。exe のプロパティ →「デジタル署名」タブで確認できる
  - 証明書を「信頼されたルート証明機関」には登録しない。署名に失敗してもビルドは成功扱い（exe はそのまま使える）

### 画像を作り直す場合

追加で Python 3 と `pip install pillow numpy scipy` が必要。

```
python tools\build_sprites.py   # assets\raw → assets\sprites
build.bat
```

- `assets\raw\` … Gemini で生成した元画像（緑背景のスプライトシート）。ファイル名と使い方は `tools\build_sprites.py` の `SHEETS` を参照
- `assets\sprites\` … 緑抜き・縮尺合わせ・足元合わせ済みの横長ストリップ（2x 解像度、全コマ同サイズのセル）
- 大きさの基準は `assets\raw\01_walk_old.jpg`（最初の歩きシート）。消さないこと
- コマ数を変えた場合は `TaskbarCat.cs` の `LoadAnim(...)` の数（歩きは `WalkFrames`）も合わせる

### ファイル構成

| ファイル | 内容 |
|---|---|
| `TaskbarCat.cs` | 本体（猫の動き・描画・右クリックメニュー・スクリプト実行） |
| `Schedule.cs` | `schedule.txt` の読み書き、cron / きまぐれの判定、日本語の説明文 |
| `ScheduleForm.cs` | スケジュール設定画面 |
| `OneShot.cs` | `oneshot.txt` の読み書き、単発バッチの設定画面 |
| `Ports.cs` | ポートを使っているプロセスの取得（WMI）、ポートの画面 |
| `tools\build_sprites.py` | 元画像 → スプライト変換 |
| `tools\package.ps1` / `package.bat` | 配布用 zip の作成 |
| `tools\sign.ps1` | exe への自己署名（`build.bat` から呼ばれる） |

## 配布手順（渡す側）

1. `package.bat` をダブルクリック
   - exe をビルドし直し（起動中の猫は一旦止めて、終わったら起動し直す）、`dist\TaskbarCat-YYYYMMDD.zip` を作る
   - 展開すると `taskbar-cat\` フォルダになる
2. できた zip を相手に渡す（チャット・ファイル共有など。メール添付は exe 入りで弾かれることがある）
3. 相手には上の「はじめかた」を読んでもらう

zip に入るのは、ソース一式、`LICENSE`、`build.bat`、`package.bat`、`tools\`、`TaskbarCat.exe`（すぐ動かせる）、`assets\sprites\`、`assets\raw\`（画像の作り直し用）。
個人のデータ（設定・スケジュール・単発バッチ・ログ）はホームフォルダか保存先にあり、作業フォルダには無いので zip には入らない。相手側では初回起動時に `schedule.txt` のサンプルが作られる。

## 注意

- exe は自己署名のみ（公的な証明書ではない）のため、初回起動時に SmartScreen の警告が出る（上記「はじめかた」参照）
